# Rust spike toolchain pins

The archives `scripts/spike/rust-wgpu/setup-toolchain.sh` installs into the project-local spike
folder (`.studio-dev/spike-toolchain/`), and the only ones it installs. Each sha256 is the checksum
the official source publishes beside the archive (last column), recorded by
`setup-toolchain.sh --pin`; a row is never rewritten, and a changed checksum is a typed refusal.
`rust-env.sh` refuses to run while an installed archive is missing from this table. CI installs
and verifies against these rows only, so a new pin is reviewed here before any runner uses it.
`scripts/toolchains/rust-env.ts` reads the same table. The table stays here, spike only, until
the store carries the Rust payload (M2.3) and its own pins replace it.
