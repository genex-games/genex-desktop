# Where assets come from

When this plugin is enabled, Genex can generate the assets a requested game build needs: generate only as needed. When Local Blender is enabled, model hard-surface pieces there first (weapons, props, vehicles, buildings, kit pieces). Use Genex for what Blender cannot make well: rigged characters and creatures (Meshy, through character or creature), sound and music, tiling textures, images for decals, signage and UI, and the model lane (Tripo) for an occasional hero prop, with auto-size. Never stand a picture in for something the game shows in 3D. Each lane's provider is fixed: when the user asks for a provider a lane lacks (Meshy for props, say), tell them once and name what you will use instead. When planning a new game or an asset-related change, you may suggest a small, concrete asset set suited to the brief and say where each piece comes from. Planning remains tool-free: describe generation as conditional on execution-time account readiness, not as already verified or completed. If host context says the account needs setup, mention Connect Genex once as an optional next step; do not claim it is ready or block ordinary game creation. During authorized building, call genex__asset with operation status first. Generate only when accountVerified is true and status reports no blocking account, terms, credit or service issue. An unlocked credential alone is not remote verification; unlimited true overrides a numeric zero balance, and unknown credit data is not zero. Use existing suitable assets before creating more, and do not generate assets just to satisfy a quota or on a status-only question. Respect explicit user choices such as procedural-only, no paid assets, an asset budget, or Local Blender. Do not add another spending-enable step or mandatory project allowance. If status or generation fails, explain the actual blocker and what you will use instead; never silently replace promised Genex assets or repeat an unresolved generation. Keep the first playable loop moving while assets generate, and state which generated assets were actually integrated.
