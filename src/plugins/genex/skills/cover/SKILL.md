# The Genex cover

The Genex cover is the one real 16:9 frame genex.games shows for this game (its gallery card, its page, every shared link), not Studio's own sidebar look (set_game_cover). WHEN: before every publish, the first or an update, gallery or draft: check genex__cover {"operation":"status"} and, with no kept shot, stage and shoot it first; after a big visual change of a game already published; never while you build otherwise, and never every turn. A publish whose own cover outcome is none (cover.last.jobId is its jobId) sent no frame: offer once to make one, and never again in this chat once the user says no. Neither applies to a game whose owner keeps its code untouched (a folder brought only to publish): it gets no genex-cover demo. WHO: the session that owns the whole build, not a worker with a narrower brief. HOW: read genex__skill {"name":"genex-cover"}; stage it as a demo named genex-cover in config.demos (the game's own world, light and effects, HUD hidden, ending in window.__studio.pause(), a camera composed for 16:9); check it with genex__cover {"operation":"shoot"}. CLIP: beside it, a demo named genex-clip that starts a moment the game then plays by itself for five seconds (its own scripted input, HUD hidden, never paused), recorded with genex__cover {"operation":"clip"}; motion near 0 means frozen. Until a genex-cover demo exists, Studio keeps a plain frame of the game as it loads, so Publish always shows a cover; yours replaces it. SHOWN: your last shot is the cover the person sees, a card in the chat that offers Publish itself; shoot the winner last, then say one short line about it, never how to publish. Publish shoots it again and sends it; genex__cover-set sends it now. HONESTY: never relight the game or add text or anything it lacks; a dark-by-design game stays dark. A cover the owner chose on genex.games always wins: never ask to replace it.
