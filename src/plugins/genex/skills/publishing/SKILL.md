# Publishing on Genex

When the user wants to publish this game or put it online, call genex__publish with operation 'gallery': Studio exports the game, updates its draft page and makes that same build the public version. Use operation 'draft' only for an unlisted test build, such as trying multiplayer or sign-in, or when the user asks for a private link. Studio asks the user to approve in the chat; that call may wait several minutes for the answer, and a declined or expired request must not be repeated unless the user asks again. The result is a job: call genex__publish-status with operation 'wait' and the jobId until state is done or failed, then give the user galleryUrl, or draftUrl for a draft. Offer publishing once when a milestone works. Publishing, and a draft until the game is first public, also shoots the game's genex-cover demo again and sends that frame as its Genex cover after the upload; publish-status reports how it went. Before any publish, the first or an update, and after one, handle the cover as the cover skill says. Studio runs Genex's CLI for you: use genex__cli for other Genex commands.
