This game needs WebGPU

Your browser or graphics hardware does not offer WebGPU, which this game draws with. There is no fallback, so the game cannot start here.

Supported browsers

  • Chrome or Edge on Windows, macOS and ChromeOS
  • Chrome on Android, on supported GPUs
  • Safari 26 on macOS, iOS and iPadOS
  • Firefox 141 or later on Windows, Firefox 147 or later on macOS

Not supported

Firefox on Linux and Android, Safari before 26, Chrome on Linux outside its WebGPU GPU list, and any browser with WebGPU turned off.

Code gpu-unsupported
